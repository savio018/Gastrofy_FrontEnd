# Regras para o agente (frontend Gastrofy)

- Toda conversão de unidade ou cálculo novo vem com teste em src/utils.
- Antes de dizer que terminou, rode npm test e npm run build e mostre a saída completa. Só diga "pronto" se passar.
- Não faça commit nem push. Liste os arquivos alterados.
- Não leia arquivos .env.
- A API recebe tudo na unidade de consumo (g, ml, un). A tela converte antes de enviar.
- Mantenha o padrão responsivo (toque de 44px, inputMode correto, sem rolagem horizontal em 360px).
