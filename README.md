# Gastrofy Frontend

Frontend do Gastrofy desenvolvido em React + TypeScript + Tailwind CSS.

## Tecnologias
- React 19
- TypeScript
- Tailwind CSS
- Vite
- Axios
- React Router DOM

## Como rodar
1. Clone o repositório
2. `npm install`
3. `npm run dev`

> ⚠️ O backend precisa estar rodando em `http://localhost:8080`
